# Móviles Alboraya

Web de muestra para **Móviles Alboraya**, tienda de reparación de móviles, tablets, portátiles y consolas en Alboraia (Valencia).

- Av. de l'Orxata, 31 · 46120 Alboraia, Valencia
- 643 61 83 00 (teléfono y WhatsApp)
- L–V 10:00–14:00 y 17:00–20:30 · S 10:00–14:00

Web estática (HTML, CSS y JavaScript con GSAP, ScrollTrigger y Lenis). Datos y reseñas tomados de su ficha pública de Google Maps. Las imágenes de la tienda y del taller están generadas con IA y son provisionales; la panorámica de Port Saplaya es de Unsplash.

Ver online: https://nocodya-hue.github.io/moviles-alboraya/
